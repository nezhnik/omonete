## 1. Авторизация и профиль

### app/login/page.tsx
- **Режим по умолчанию:** при открытии страницы теперь сразу «Вход» (`mode = "in"`), а не «Magic link».
- **Сообщения об ошибках по-русски:** добавлена функция `mapAuthError`:
  - «Неверный email или пароль» — при неверном логине (invalid login credentials);
  - «Пароль должен содержать минимум 6 символов» — при регистрации с коротким паролем;
  - «Пользователь с таким email уже зарегистрирован» — при дубликате;
  - общая фраза «Произошла ошибка. Попробуйте ещё раз» для остальных случаев.
- После успешного входа/регистрации — редирект в портфолио (как и раньше).

### app/profile/page.tsx
- **Смена пароля:** добавлен блок «Сменить пароль»:
  - поля: текущий пароль, новый пароль, повтор нового;
  - проверки: все поля заполнены, пароли совпадают, новый не короче 6 символов;
  - вызов `changePassword(currentPassword, newPassword)` из `useAuth()`;
  - сообщения: «Текущий пароль указан неверно», «Пароль успешно изменён», «Новые пароли не совпадают» и т.д.
- Подпись поля «Имя и фамилия» заменена на «Имя».

### components/AuthProvider.tsx
- **Новая функция в контексте:** `changePassword(currentPassword, newPassword)`:
  - проверка текущего пароля через `signInWithPassword`;
  - при успехе — `updateUser({ password: newPassword })` (Supabase);
  - возвращает ошибку `"INVALID_CURRENT_PASSWORD"` или сообщение от API.
- `changePassword` добавлена в тип контекста и в значение по умолчанию (заглушка, если провайдер не подключён).

## 2. Страница монеты и отображение веса

### components/CoinDetail.tsx
- **Тип `CoinDetailData`:**
  - добавлено поле `weightOzDisplay?: string` — «для строки „Вес в унциях“: у кг — унции по расчёту (32,15 унции), иначе — weight_oz из БД»;
  - в комментарии к `weightOz` уточнено, что для блока «Вес в унциях» лучше использовать `weightOzDisplay`.
- **Блок характеристик, строка «Вес в унциях»:**
  - раньше показывали: `coin.weightLabel ?? coin.weightOz`;
  - теперь показываем: `coin.weightOzDisplay ?? coin.weightOz` (приоритет у рассчитанных унций для кг);
  - условие показа строки расширено: учитывается и `weightOzDisplay`.

Итог: для монет 1 кг, 2 кг, 3 кг, 5 кг, 10 кг в блоке «Вес в унциях» отображаются рассчитанные унции (32,15; 64,30; 96,45; 160,75; 321,51), для остальных — по-прежнему значение из БД (`weight_oz`).

### lib/coinApiShape.ts
- **Таблица весов для лейблов:** в `WEIGHT_OZ_TO_LABEL` добавлены: «2 кг», «10 кг», «1.5 унции», «2.5 унции».
- **Килограммовые монеты → унции для отображения:** новая таблица `KG_OZ_DISPLAY` (граммы → строка для блока «Вес в унциях»):
  - 1000 г → «32,15 унции»;
  - 2000 г → «64,30 унции»;
  - 3000 г → «96,45 унции»;
  - 5000 г → «160,75 унции»;
  - 10000 г → «321,51 унции».
- **Функция `getWeightOzDisplay(weightG, weightOz):** для кг (≥999 г и значение из таблицы) возвращает строку из `KG_OZ_DISPLAY`, иначе — `weightOz` из БД. Используется при формировании данных для страницы монеты (в экспорте/API).
- В список `WEIGHT_LABELS` добавлены: 2 кг (2000 г, допуск 10), 10 кг (10000 г, допуск 50).
- В тип `DetailCoin` добавлено поле `weightOzDisplay?: string` с комментарием.
